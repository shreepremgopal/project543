# TASK 1.2 — Install Git

We need Git from the beginning because the repository becomes our project's safety net.

Use the official Git website:

[Git for Windows — official download](https://git-scm.com/install/windows?utm_source=chatgpt.com)

Download and install **Git for Windows**.

### Installer choices

The installer contains many options. For now, use the defaults.

When you encounter the option concerning the default editor, it is fine to leave the default or choose VS Code if the installer offers it and you are comfortable doing so.

For PATH-related options, keep the recommended/default option that allows Git to be used from the command line.

For line endings, keep the recommended Windows setting.

Don't customize advanced Git behavior yet.

### Verify

Open **PowerShell**.

Press:

**Windows key → type `PowerShell` → Enter**

Run:

```powershell
git --version
```

You should receive a Git version.

For example:

```text
git version 2.x.x
```

The exact patch version isn't important as long as Git runs successfully.

### Definition of Done

* Git installed
* `git --version` works
